# Vidéo de démonstration LinkedIn — scénario (25 secondes)

**Format recommandé** : vertical **1080×1350 (4:5)** — le format qui occupe le plus d'espace dans le fil LinkedIn — ou carré **1080×1080**.
**Durée** : 25 secondes. **Son** : optionnel (la plupart des vidéos sont regardées sans le son) ; une musique ambient/électronique douce fonctionne bien.

## Idée de mise en page

Composition en deux zones, empilées verticalement :

```
┌──────────────────────┐
│  TEXTE À L'ÉCRAN     │  ← bandeau haut (titres courts)
├──────────────────────┤
│                      │
│  CAPTURE DE L'ÉCRAN  │  ← la galaxie (zone principale)
│  (galaxie)           │
│                      │
├──────────────────────┤
│  VOTRE MAIN (webcam  │  ← incrustation de la main réelle,
│  ou téléphone)       │     pour que le lien geste → effet soit évident
└──────────────────────┘
```

L'aperçu webcam de l'application (en bas à droite, avec le squelette de la main) montre déjà le geste : vous pouvez simplement recadrer l'écran pour qu'il reste visible.

## Plan par plan

| Temps | Ce qu'on voit | Texte à l'écran |
| --- | --- | --- |
| **0–3 s** | Écran d'accueil : la galaxie tourne à côté du titre GESTURE GALAXY. | **Et si vous pouviez contrôler l'univers… du bout des doigts ?** |
| **3–6 s** | Clic sur « Commencer l'expérience », les étapes de chargement se valident, la galaxie apparaît avec une première onde de lumière. | **Juste une webcam. Aucune installation.** |
| **6–10 s** | La main s'ouvre lentement face à la caméra : la galaxie s'étend, les bras spiraux se dessinent. | **✋ Main ouverte → expansion** |
| **10–14 s** | La main se ferme : les étoiles tourbillonnent vers le noyau qui s'illumine. | **✊ Poing fermé → contraction** |
| **14–18 s** | Main ouverte, balayage de gauche à droite (puis un mouvement vers le haut) : la galaxie tourne et la vue bascule. | **↔ La galaxie suit votre main** |
| **18–22 s** | Gros plan : pouce et index se pincent → explosion radiale, onde de choc, changement de couleur. Refaire un 2ᵉ pincement pour une autre couleur. | **🤏 Pincement → explosion de lumière** |
| **22–25 s** | Plan final : la galaxie se recompose et tourne doucement. Titre + lien. | **GESTURE GALAXY · Essayez-la dans votre navigateur ↗** |

## Conseils de tournage

1. **Préparez la scène** : passez en plein écran (bouton ou touche F), faites « Réinitialiser la galaxie » (touche R) juste avant d'enregistrer.
2. **Éclairage** : une lumière face à vous (fenêtre ou lampe), un fond neutre derrière la main. La détection est bien meilleure quand la main est bien éclairée.
3. **Distance** : main entière dans le cadre, à 40–80 cm de la caméra, paume tournée vers l'écran.
4. **Des gestes lents et amples** : tenez chaque geste 2 à 3 secondes, la galaxie a besoin d'un instant pour s'animer pleinement.
5. **Fluidité** : fermez les autres onglets et applications lourdes ; branchez l'ordinateur sur secteur.
6. **Faites plusieurs prises** et gardez les meilleurs passages pour chaque geste.

## Comment enregistrer

- **Écran** :
  - Windows : `Win + Alt + R` (Xbox Game Bar) ou [OBS Studio](https://obsproject.com/) (gratuit).
  - macOS : `Cmd + Maj + 5` → « Enregistrer tout l'écran », ou OBS Studio.
- **La main (facultatif)** : filmez votre main avec un téléphone posé à côté de l'ordinateur, ou ajoutez dans OBS une seconde source « Périphérique de capture vidéo » (votre webcam).
- **Montage et format 4:5** : CapCut, DaVinci Resolve (gratuits), Clipchamp (Windows) ou iMovie. Créez un projet 1080×1350, placez la capture d'écran au centre, la main en bas, et ajoutez les textes ci-dessus (police large, blanche, avec une légère ombre).
- **Export** : MP4 (H.264), 30 i/s, 1080×1350.

## Sous-titres / texte alternatif (accessibilité)

> Démonstration de GESTURE GALAXY : une main devant une webcam contrôle une galaxie 3D. Main ouverte, la galaxie s'agrandit ; poing fermé, les étoiles se contractent vers le centre ; un mouvement latéral la fait tourner ; un pincement des doigts déclenche une explosion de lumière.
